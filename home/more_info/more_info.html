More About This Website


Everything you see here was hand crafted in Vim on Debian Linux and written by me, not AI. I appreciate you stopping by.

Vim is a command-line text editor and an IDE for coding. I like its simplicity and despite it making development slower, I have enjoyed learning this ancient (in the computing terms) skill. Read more about Vim here.

This website is the place where I archive my thoughts, a place where anyone on Earth can find out a little bit about me. This website will outlast me and be a place where my descendants and internet historians can go to find out who I was. There is no view counter, like button, or comment section on this website for a reason, it's just me, writing in the command line (the way God intended the computer to be used).

There is something I like about a webpage with little to no javascript, just good old HTML. What you see is what you get, no randoms scripts running in the background, gathering every data point possible about you, the reader, to sell to an advertiser.

The topics I like are finance, self development and maybe a bit of philosophy from time to time.

If you have any cool ideas for me to add to the page, let me know.
