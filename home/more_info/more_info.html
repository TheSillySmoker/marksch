More About This Website


This website is my brain-child and in some ways, my lifes work.

Everything you see here was hand crafted in Vim on Debian Linux and written by me, not AI. I appreciate you stopping by.

This website is the place where I archive my thoughts, where anyone on Earth can find out a little bit about me. It will outlast me and be a place where my descendants and internet historians can go to find out who I was. If you would like to keep this website alive after I'm gone, you can find the source code (containing all articles within HTML files) on Github here.

There is no view counter, like button, or comment section on this website, it's just me, writing in the command line (the way God intended the computer to be used). What you see is what you get, no scripts running in the background, gathering every data point possible about you to sell to an advertiser.

The topics I like are finance and self development.

If you have any cool ideas for me to add to the page, let me know.
